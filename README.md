# Тренажёр ритма

Бесплатный веб-тренажёр ритма (PWA). Сейчас это прототип этапа 0: метроном, тапы, калибровка задержки и отклонение каждого тапа в мс.

```bash
npm install
npm run dev     # http://localhost:5173, доступно и с телефона в той же Wi-Fi сети
npm test        # юнит-тесты логики тайминга
npm run build   # статическая сборка в dist/
```

## Устройство

- `src/audio/engine.ts` — Web Audio: разблокировка на iOS, щелчки, перевод времени события в аудиовремя (`getOutputTimestamp`).
- `src/audio/metronome.ts` — метроном с упреждающим планированием по аудиочасам.
- `src/core/timing.ts` — чистая логика: сопоставление тапов с долями, оценка, калибровка.
